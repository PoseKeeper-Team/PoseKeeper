# 기능 명세서: 트레이 앱/대시보드

## 1. 목적

PoseKeeper를 장시간 백그라운드에서 실행하고, 사용자가 필요할 때만 대시보드를 열어 현재 자세 상태와 통계를 확인할 수 있게 한다.

## 2. 대상 파일

| 파일 | 역할 |
|---|---|
| `main.py` | 앱 진입점 |
| `src/app/tray.py` | 시스템 트레이 아이콘과 메뉴 |
| `src/app/dashboard.py` | Tkinter 대시보드 UI |
| `src/inference/predictor.py` | 실시간 상태 결과 제공 |
| `src/app/alert.py` | 트레이 실행 중 알림 발생 |

## 3. 트레이 기능

### 메뉴 구성

| 메뉴 | 동작 |
|---|---|
| 상태 표시 | 현재 상태 요약 표시 |
| 대시보드 열기 | Tkinter 대시보드 창 열기 |
| 일시정지/재개 | 백그라운드 추론 중지 또는 재개 |
| 설정 | 민감도, 알림 여부 등 설정 창 또는 메뉴 |
| 종료 | 웹캠/스레드/트레이 리소스 정리 후 종료 |

### 백그라운드 동작

1. `main.py`가 `run_tray()`를 호출한다.
2. 트레이 앱이 시작되면 추론 스레드를 생성한다.
3. 추론 스레드는 웹캠을 열고 `bg` 모드로 predictor를 실행한다.
4. 위험 이벤트 발생 시 알림 기능에 이벤트를 전달한다.
5. 종료 시 웹캠, 스레드, DB 연결을 정리한다.

대시보드가 열리면 별도 `VideoCapture`를 만들지 않는다. 기존 추론 스레드가 단일 웹캠 핸들을 유지한 채 `dashboard` 모드로 승격되고, 대시보드가 닫히면 다시 `bg` 모드로 복귀한다.

### 런타임 ownership 계약

- `tray`가 단일 `cv2.VideoCapture` 인스턴스를 소유한다.
- 프레임 읽기는 추론 스레드 1개만 담당한다.
- `dashboard`는 웹캠을 직접 열지 않고 공유된 latest frame과 latest inference result만 읽는다.
- 모드 전환은 공유 상태값 `bg` / `dashboard`만 변경하고 캡처 객체를 재생성하지 않는다.
- 공유 데이터 접근에는 lock 또는 thread-safe queue 중 하나를 사용한다.

## 4. 대시보드 기능

### 표시 항목

| 영역 | 내용 |
|---|---|
| 웹캠 영상 | 현재 프레임 표시 |
| 랜드마크 오버레이 | Pose / FaceMesh 주요 점 표시 |
| 현재 상태 | 정상, 거북목, 졸음, 딴짓, 이상 자세 |
| 자세 점수 | 0~100 점수 |
| 지속 시간 | 위험 상태가 유지된 시간 |
| 시간대별 그래프 | 최근 자세 점수/이벤트 변화 |
| 세션 요약 | 시작 시간, 평균 점수, 알림 횟수 |

## 5. UI 상태

| 상태 | 표시/동작 |
|---|---|
| 정상 실행 | 영상과 상태 갱신 |
| 일시정지 | 추론 중지, 마지막 상태 유지 |
| 웹캠 없음 | 영상 영역에 오류 메시지 표시 |
| 모델 없음 | 해당 모델 상태를 비활성 또는 준비 안 됨으로 표시 |
| 대시보드 닫힘 | 백그라운드 추론은 계속 유지 |

## 6. 스레드/리소스 정책

| 리소스 | 정책 |
|---|---|
| 웹캠 | 백그라운드와 대시보드가 단일 `VideoCapture`를 공유하며 중복 점유하지 않는다 |
| 추론 스레드 | 트레이 시작 시 1개 생성 |
| 모드 전환 | 대시보드 open 시 `dashboard`, close 시 `bg`로 전환 |
| Tkinter | 메인 스레드 제약을 고려해 창 생성/갱신 방식 통일 |
| 종료 | `VideoCapture.release()`, DB flush, 트레이 stop 호출 |

## 7. 대시보드 갱신 주기

| 항목 | 권장 주기 |
|---|---:|
| 영상 프레임 | 30fps 이하 |
| 추론 결과 | frame skip 적용 후 5~10fps 수준 |
| 그래프 | 1초 단위 |
| 세션 통계 | 5초 단위 |

## 8. 예외 처리

| 상황 | 처리 |
|---|---|
| `pystray` import 실패 | 설치 안내 메시지 출력 |
| Tkinter import 실패 | 환경 설정 안내 메시지 출력 |
| 대시보드 중복 열기 | 기존 창 focus |
| 카메라 점유 실패 | 단일 캡처 초기화 실패로 간주하고 오류 표시 후 재시도 버튼 제공 |
| 종료 중 스레드 미종료 | timeout 후 강제 정리 로그 출력 |

## 9. 완료 기준

- `python main.py`로 트레이 앱이 실행된다.
- 트레이 메뉴에서 대시보드를 열 수 있다.
- 대시보드를 닫아도 트레이 앱은 계속 실행된다.
- 일시정지/재개가 실제 추론 루프에 반영된다.
- 대시보드 open/close에 따라 단일 캡처 루프가 `bg`/`dashboard` 모드로 전환된다.
- 종료 시 프로세스가 남지 않는다.
- 웹캠 오류가 발생해도 앱이 비정상 종료되지 않는다.
